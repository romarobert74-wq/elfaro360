# Logos de El Faro 360

El logo del sistema (menú, login y PDF de presupuestos) está hecho en **vector
(componente `components/Logo.tsx`)**, así que se ve nítido a cualquier tamaño y
se adapta al color del fondo (blanco en el menú oscuro, negro en el PDF).

## ¿Querés usar tus archivos PNG exactos?

Si preferís el archivo original en algún lugar puntual (por ejemplo el
encabezado del PDF), subí los PNG a esta carpeta con estos nombres:

- `logo-blanco.png`  → versión con texto blanco (para fondos oscuros: menú/login)
- `logo-negro.png`   → versión con texto negro (para el PDF sobre fondo blanco)
- `logo-icono.png`   → versión cuadrada/apilada (para favicon o redes)

Cómo subirlos sin usar la terminal:
1. Entrá al repo en GitHub → carpeta `public/brand/`.
2. **Add file → Upload files** → arrastrá los PNG → **Commit changes**.
3. Avisame y los conecto en el código (menú y/o PDF).

> Ideal: fondo transparente y buena resolución (mínimo ~1000 px de ancho).
